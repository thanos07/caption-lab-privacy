# Caption Lab privacy policy

Public privacy policy for **Caption Lab — YouTube Captions**, version 1.3.0.

The policy is served as a static page by GitHub Pages. It contains no JavaScript, analytics, external fonts or other remote assets.

Contact: [noorali99307@gmail.com](mailto:noorali99307@gmail.com). Developer location: India.

To update the policy, edit `index.html` and commit to `main`. GitHub Pages serves the repository root; `.nojekyll` keeps the page static. Keep the published wording consistent with the policy shipped in the extension.

This repository contains the privacy-policy site, not the extension source or release package.
